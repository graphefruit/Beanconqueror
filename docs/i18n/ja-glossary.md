# Beanconqueror 日本語ローカライズ用語集 (Glossary)

本ドキュメントは `src/assets/i18n/ja.json` の翻訳一貫性を保つための用語集です。
コーヒー専門用語は **「英語のまま」「カタカナ」「日本語訳」** のいずれを採用するかを用語ごとに判断し、その根拠を記録します。

> 方針: 日本のコーヒー業界・スペシャルティコーヒー界隈で**実際に最も通じる表記**を優先する。
> アプリ名 **"Beanconqueror"** は英字のまま（翻訳しない）。

---

## 1. 文体・表記ルール

| 項目 | ルール |
| --- | --- |
| 文体 | 「です・ます」調の丁寧語 |
| 句読点 | 「、」「。」（全角） |
| 数字 | 半角（例: `30g`, `92°C`, `15 bar`） |
| 単位 | 半角の英字単位（`g`, `ml`, `bar`, `rpm`, `°C`, `ppm`）を温存 |
| 半角/全角の間 | カタカナと英数字の間にスペースを入れない（例: `カッピング機能` ではなく必要に応じて自然な表記） |
| ボタン | 体言止め（「保存」「削除」「追加」「キャンセル」） |
| プレースホルダ | `{{value}}`, `%s` 等は**そのまま保持** |
| HTML/改行 | `<br>`, `<b>`, `\n` は**そのまま保持** |
| 固有名詞 | アプリ名・サードパーティ名（Beanconqueror, Acaia, Decent, Meticulous, Gaggiuino 等）は英字のまま |
